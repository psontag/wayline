# UI

Desktop first. Phones get a viewing-first layout.

Mockups are in `design/` (see `design/README.md`).

## Screens

| Screen | Purpose |
|---|---|
| Trip list | Own trips and trips shared with me. Button for a new trip. Empty state with a short hint and the new trip button. |
| New trip | Choose mode and enter parameters. |
| Proposals | Compare generated trips and pick one. |
| Trip editor | View and edit a trip. Main screen. |
| Route A to B | One route between two points. Can be saved as a one-stage trip. |
| Shared view | Trip editor without editing. |
| Settings | Theme and language. |

## New trip

Modes: multi-day one-way, multi-day loop, route A to B, day loop.

Inputs depend on the mode:

- region on the map or start station
- days, km per day, max ascent per day
- profile, hotel budget
- start date (optional)

```
│                              │ Routing 3 of 5 Cancel│
│                              ├──────────────────────┤
│     Map with all proposals,  │ 1  4 days · 312 km   │
│     numbered. Unselected     │    2,100 m · 85% paved│
│     ones are dimmed.         ├──────────────────────┤
│                              │ 2  ...               │
│                              ├──────────────────────┤
│                              │ 3  ...               │
└──────────────────────────────┴──────────────────────┘
```

- Cards appear as they finish. A progress line and a Cancel button sit on top.
- Proposals are numbered on the map. Unselected ones are dimmed.
- Hover a card to highlight the route.
- Opening a proposal creates a draft trip. Going back shows the same proposals.
- No result: say which limit failed and offer to relax it.

## Route A to B

Path `/route`. Start, end and profile live in the search params, so a route can be shared as a link. It looks like the trip editor: map with the elevation profile below, panel on the right.

- Set start and end by search (towns and stations) or by clicking the map. Drag a marker to move it.
- A clicked point is named after the nearest town within 5 km.
- Profile: touring, fast, scenic, quiet.
- Panel: distance, ascent, descent, paved share and surface bar.
- "Save as trip" stores a one-stage trip of kind `route` and opens it in the editor. "Export GPX" downloads the route.
- Each leg is cached on its own. Only legs with a changed end are routed again.
- Entry point: "Route A to B" next to "New trip" on the trip list.

## Trip editor

```
┌──────────────────────────────┬──────────────────────┐
│                              │ Day 1 · Sat 12 Jun   │
│                              │ Bamberg → Coburg  [L]│
│                              │ 78 km · 650 m        │
│           Map                │ 22 °C · 70% tailwind │
│                              │ Hotel Goldene Rose   │
│                              ├──────────────────────┤
│                              │ Day 2 · Sun 13 Jun   │
│                              │ ...                  │
├──────────────────────────────┴──────────────────────┤
│ Elevation profile, colored by surface                │
│ Weather strip: temperature, rain, wind               │
└──────────────────────────────────────────────────────┘
```

`[L]` is the lock toggle on the stop. Icons are Lucide.

Top bar: trip name, save state, undo/redo, start date, settings, GPX export, share, trip menu (rename, duplicate, delete).

### Interactions

| Action | How |
|---|---|
| Select stage | Click card or route on map. Map zooms to the stage. |
| Add via point | Drag the line. The route updates on drop. |
| Remove via point | Click it. |
| Move stop | Pick one of the suggested towns, or drag the stop marker. The stop gets locked. |
| Lock stop | Lock toggle on the stage card. |
| Change hotel | Hotel list for the stop: name, stars if known, distance to route. |
| Booking.com | One link per stop with dates, budget and rating filter. Per hotel: link to its website if OSM has one. |
| Trains | bahn.de links at start and end stations. |
| Change date | Edit start date. Dates and weather update. |
| Export | Whole trip, or one stage. |

- Changes save automatically.
- After an edit, a short note shows downstream changes, e.g. "Day 3 now ends in Lichtenfels".
- While derived data loads, old values stay visible and are marked as updating.

### Elevation and weather

- Elevation and weather share one km axis.
- Hover shows a crosshair and a marker on the map.
- Weather is shown for the expected time at each km.
- The stage card shows wind as a share of the distance (head, tail, cross) and the average wind speed.
- Beyond the forecast range: "Forecast from <date>".

## Phone layout

- Viewing first.
- Map with a bottom sheet at three heights: peek, half, full.
- Editing only by picking stop alternatives and hotels. No route dragging.

## Accessibility

- Every map action also works from the side panel.
- Proposals are numbered, not marked by color only.
- Reduced motion is respected.
