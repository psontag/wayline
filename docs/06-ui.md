# UI

Desktop first. Works on phones with a stacked layout.

## Screens

| Screen | Purpose |
|---|---|
| Trip list | Own trips and trips shared with me. Button for a new trip. |
| New trip | Choose mode and enter parameters. |
| Proposals | Compare generated trips and pick one. |
| Trip editor | View and edit a trip. Main screen. |
| Shared view | Trip editor without editing. |

## New trip

Modes: multi-day one-way, multi-day loop, route A to B, round trip.

Inputs depend on the mode:

- region on the map or start station
- days, km per day, max ascent per day
- profile, hotel budget, minimum hotel rating
- start date (optional)

### Interactions

| Action | How |
|---|---|
| Select stage | Click card or route on map. Map zooms to the stage. |
| Change route | Drag the line on the map to add a via point. |
| Move stage end | Pick one of the suggested towns, or drag the end marker. |
| Change hotel | Open the hotel list for the stage end. Shows rating, price level, distance to route, booking link. |
| Change date | Edit start date. All dates and weather update. |
| Export | Whole trip, or one stage. |

Wind is shown relative to the direction of travel: headwind, tailwind, crosswind.

While derived data loads, old values stay visible and are marked as updating.

## Phone layout

Map on top. Stage list as a bottom sheet. Elevation and weather inside the selected stage.
