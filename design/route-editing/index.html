Route editing on phone, iPad and desktop

Every device gets the same actions. The input decides the gesture: a finger works differently from a mouse. Screen width only decides the layout.

Three devices, two inputs

The layout switches at 768 px. Every iPad is wider than that, so it gets the desktop layout. Today the desktop layout only works with a mouse.

Gestures

Each pointer event says whether it comes from a mouse, a pen or a finger. Use that, not the layout. An iPad with a trackpad gets the mouse column. Pencil uses the touch column.

Build order

Each slice works on its own and can ship by itself.

Select instead of remove

Selected state, Move and Remove, undo toast, 44 px hit area, via list in the panel. Small, and it ends accidental deletes everywhere.

Input-based gestures

Choose by pointer type. Touch on iPad works. Keyboard shortcuts for undo, redo, Esc and Delete.

Edit mode

Centre pin, live preview, change in km and ascent. Sheet on phone, floating bar on iPad. Desktop gets the preview for moving a via.

Route via here

Long-press and right-click open the same menu, then edit mode. Snaps to the nearest leg of the selected day.
